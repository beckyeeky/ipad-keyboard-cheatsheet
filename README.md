# iPad Keyboard Cheatsheet

Interactive cheatsheet for documented iPad external-keyboard shortcuts.

Open the page: <https://beckyeeky.github.io/ipad-keyboard-cheatsheet/>

The page groups shortcuts by modifier layer. It does not include `Command-Shift-5`, region capture, or a screen-recording shortcut because Apple Support does not document those shortcuts for iPad.

Sources checked on 2026-10-03:

- <https://support.apple.com/en-us/102393>
- <https://support.apple.com/en-us/125309>
- <https://support.apple.com/guide/ipad/use-quick-notes-ipad5d91fd88/ipados>
- <https://support.apple.com/guide/ipad/control-ipad-with-an-external-keyboard-ipad5f765d6f/ipados>
